# Migrations

Здесь будут нумерованные SQL-миграции:

```
001_init_user_profile.sql
002_locations.sql
003_oauth_tokens.sql
...
```

Подробности структуры — в `docs/architecture.md`, раздел 5.0.12.

**Правила:**
- Номера непрерывные, без пропусков
- Один файл = одно логическое изменение
- Старые миграции не правятся — только новые
- Откат (rollback) — в комментариях того же файла, не отдельным файлом
