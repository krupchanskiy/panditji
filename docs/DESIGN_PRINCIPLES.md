# Panditji — Design Principles

Краткие правила для мелких правок без участия дизайнера/Claude. Берётся как fact, без обсуждения.

---

## 1. Базовая ширина — 360px

- Всё проектируется и проверяется на **360px wide** (узкий Android — устройство пользователя)
- НЕ 375, НЕ 380. На 360 ломается всё, что спроектировано шире
- Если на 360 не помещается — переносим на 2 строки **как штатное поведение**, не лечим уменьшением шрифта
- Боковые отступы карточек — 16px max с каждой стороны (`margin: 0 16px`)
- 3 метрики в ряду = ~110px колонка минус gap. Хватает только на короткое слово + цифру + дельту
- Чекбоксы и тап-зоны — минимум 44×44px, текст рядом ~280px (закладывать перенос)

---

## 2. Цвета — по ролям, не для красоты

Шесть акцентов, каждый имеет **одну семантику**. Не реиспользовать «потому что красиво».

| Цвет          | Роль                                                                      |
|---------------|----------------------------------------------------------------------------|
| **terra** (rose/peach) | WARNING, экадаши, паксха, хвосты задач, локация-точка             |
| **sage** (sky blue)    | CALM/INFO — Recovery, Sleep, восстановление, вода                 |
| **gold** (lavender)    | HRV, Календарь, второстепенные метрики                            |
| **saffron**            | Большие праздники (Янмаштами, Нрисимха, явления)                  |
| **green** (jade)       | Джапа, SUCCESS (фасты активны), практика                          |
| **ink** (indigo deep)  | Сильный текст, тёмные кнопки, шапка                               |

**Правила**:
- Никаких ярких/насыщенных цветов. Всё в oklch, низкая хрома
- Не вводить новые цвета — используем `color-mix(in oklch, var(--accent) X%, transparent)` для оттенков
- Глассморфизм карточек: `rgba(255,255,255, 0.55-0.62)` фон + `backdrop-filter: blur(22px) saturate(140%)`
- Каждый раздел приложения имеет свой цветовой тинт + spine (3px цветная полоса слева)

---

## 3. Дельты — одна логика, всегда

Цвет применяется **только к дельте** (числу со знаком), не к основной цифре.

- **Положительная дельта** (улучшение): `--green-deep`
- **Нейтральная зона** (|δ| ≤ 5% от baseline): `--text-2` (как обычный текст)
- **Отрицательная дельта**: `--neg-deep` (приглушённая терра)
- **Нейтральные метрики** (Strain, вес): всегда серый, **никогда не окрашиваются**
- **Инверсия** (где «ниже = лучше», пример: пульс покоя): знак минус становится положительным = зелёным

Никаких стрелок ↑↓, никаких эмодзи 🟢🔴, никаких градиентов в цифрах. Только знак + число.

---

## 4. Типографика — два шрифта, две роли

**Manrope** — всё UI, числа, кнопки, лейблы, имена задач, текст карточек.
**EB Garamond** (regular + italic) — используется только для:

- Заголовков страниц (`page-head` в EB Garamond 20px)
- Личного голоса Пандитджи (только утренний экран)
- Дат и time-window («сегодня», «вчера», «через 1ч 20м», «паран 16 мая · 09:14–09:42»)
- Eyebrow-подписей внутри карточек («Последние сессии», «Хвосты», «Сегодня», «Завтра»)
- Sparse-notes (пустые состояния: «На сегодня всё.», «Соберём ещё неделю.»)
- Цитат и заметок в drawer'ах

**Правила**:
- Не использовать Garamond для чисел и UI-кнопок — он там не читается
- Не использовать Manrope для personal-voice строк («доброе утро, …») — холодно
- Все числа — `font-variant-numeric: tabular-nums` через утилиту `.num`
- Десятичные — запятая (`12,5`), не точка
- Никаких новых шрифтов

---

## 5. Поверхности — стекло, мягкие тени, ничего «коробочного»

- Карточки: rounded **18px** (`.hc`), стейдж rounded **32-40px**
- Чипы/pills: rounded **999px**
- Поля ввода: rounded **14-16px**
- Тени мягкие, на основе индиго, **никаких** drop-shadow с тёмным offset:
  ```css
  box-shadow:
    0 1px 0 rgba(255,255,255,0.9) inset,
    0 1px 2px oklch(0.30 0.06 250 / 0.04),
    0 10px 26px -18px oklch(0.30 0.06 250 / 0.18);
  ```
- Хейрлайны — `linear-gradient(transparent, var(--hairline), transparent)` или `color-mix(in oklch, var(--ink) 12%, transparent)`. **Не сплошной серый.**

---

## 6. Иконки — тонкие, currentColor

- Все иконки — inline SVG, `stroke="currentColor"`, `stroke-width="1.5-2"`, `stroke-linecap="round"`
- Размер обычно 12-16px
- Не использовать иконки-шрифты (FontAwesome, Material), не вставлять иконки-PNG
- Не добавлять иконки для красоты — только когда они несут смысл (камера = онлайн-встреча, чекбокс = выполнить)
- Никаких эмодзи в chrome интерфейса. Эмодзи допустимы только в **тексте задач**, если пользователь сам их пишет

---

## 7. Лунный набор — единый источник истины

Используем единый набор `<symbol id="moon-XX">` (8 фаз) в скрытом `<defs>` блоке. Подключается один раз на страницу через `<svg>...<defs>...</defs></svg>`.

Использование: `<svg width="N" height="N"><use href="#moon-waning-crescent"/></svg>`

- `#moon-new` — пустой круг
- `#moon-waxing-crescent`, `#moon-waxing-gibbous`, `#moon-first-quarter`
- `#moon-full` — залитый круг
- `#moon-waning-gibbous`, `#moon-waning-crescent`, `#moon-last-quarter`

Маппинг к вайшнавским дням (см. `vaishnavaIcon`):
- экадаши → `#moon-waning-crescent`
- двадаши → `#moon-waning-gibbous`
- пурнима/полнолуние → `#moon-full`
- амавасья/новолуние → `#moon-new`
- остальное → `#moon-waxing-gibbous`

Не рисовать луну заново. Не использовать эмодзи 🌙.

---

## 8. Тон копирайта

**Стиль**: нейтральный, безличный, тихий. Как личный дневник, не как уведомление.

✅ **Можно**:
- «Перенести», «Добавить», «Удалить», «Готово» — инфинитивы и краткие глаголы
- «На сегодня задач нет.», «Все задачи на сегодня сделаны.» — констатация
- «через 1ч 20м», «с пятницы», «3 дня назад» — относительные даты
- «14 мая», «11 мая · 16:42» — абсолютные даты где нужно

❌ **Нельзя**:
- Восклицательные знаки
- «Вы»/«ты» — нейтральная безличная форма
- Мотивационные фразы («Готов покорять день!», «Отлично!», «Так держать!»)
- «Привет», «Доброе утро» как обращение — это только в личном сообщении Пандитджи на утреннем экране
- Извинения от системы («К сожалению, не удалось…», «Извините, …»)

---

## 9. Чего избегать (бан-лист)

❌ Эмодзи в chrome ❌ Восклицательные знаки ❌ Прогресс-бары к цели («N% from goal»)
❌ Геймификация — стрики счётчиком очков, бейджи, кубки, медали, share-кнопки
❌ Яркие/насыщенные цвета — всё через oklch, низкая хрома
❌ Drop-shadow с тёмным offset (как у Material). Тени только мягкие, светлые
❌ Тосты «Вы выполнили!» — нейтральный тон: «Выполнено»
❌ Иконки-зацепки (стрелки ↑↓ у дельт, чевроны без необходимости)
❌ Tooltips. Если лейбл нужно объяснить — лейбл плохой
❌ Скелетоны-пульсации. Простая высота карточки без анимации, или sparse-note
❌ Темная тема через автоматическое переключение по media-query — только явный toggle (и не на главной)
❌ Tabs, filters, projects в задачах. Один список, без вложенности
❌ Title из вежливости («Главная страница», «Добро пожаловать»). Просто экран

---

## 10. Стрики / достижения — минимум

- Показываем стрики **только если ≥3 дней подряд**
- Мелким серым шрифтом, в одну строку, без иконок: `26 дней по 16 кругов`, `12 ночей сон ≥ 7ч`
- Размещение: под цифрами свёрнутого состояния либо в развёрнутом виде
- **Никаких** кубков, огоньков 🔥, медалей. Только текст
- Не подкреплять словесно («Отличный стрик!»). Просто число
- Круглые числа (100-я сессия, 1000 кругов) — короткой строкой в развёрнутом виде, italic Garamond

## 11. Компонентная гигиена

### Page-head (на каждой не-главной странице)
```html
<div class="page-head">
  <button class="back-btn"><!-- chevron-left --></button>
  <div class="title">Название</div>
  <button class="home-btn"><!-- home icon --></button>
</div>
```

- Капсула rounded 999px, glass background, margin `16px 16px 4-14px`
- Back-btn = chevron-left, `history.back()`
- Home-btn = lucide home, всегда → `/` (главная)
- Title в **EB Garamond 20px**, font-weight 500
- Обе кнопки 36×36 круг

### Главная (домашний экран)
- Шапка собственная (3 колонки: дата+экадаши | лого | локация+температура), не использует `page-head`
- 4 карточки stack: Джапа, Здоровье, Задачи, Календарь — **фиксированный порядок**, без перетасовки

### Карточка с метриками (3 столбца)
- `display: grid; grid-template-columns: repeat(3, 1fr); gap: 8px;`
- Каждая ячейка: label (uppercase 9.5px) → today (24px tabular) → baseline (10.5px) → delta (11px)

### Bottom-sheet
- Кремовый градиент, rounded `24px` сверху
- Drag-handle сверху
- Padding `12px 16px 22px`
- Поверх scrim'а
- Используется для date-picker, детали задачи, location picker

### Чекбокс
- 24×24px, rounded **7px**, border 1.5px из `color-mix(in oklch, var(--ink) 18%, transparent)`
- Фон: `rgba(255,255,255, 0.7)`
- Done: заливка `var(--ink-2)`, белая галка с transition 200ms
- Тень в done: `0 3px 8px -3px oklch(0.30 0.06 250 / 0.45)`
- Текст рядом в done: `text-decoration: line-through; color: var(--text-3)`

---

## 12. Принцип ничего лишнего

- Никаких декоративных элементов «для красоты»
- Если секция кажется пустой — это **проблема композиции**, а не повод добавить контент
- Один thousand "no" for every "yes"
- Не добавлять иконки/числа/чипы потому что «выглядит голо»
- Сомневаешься — убрать
- Лучше пустое пространство, чем заполнитель

---

## 13. Числа и форматы

- Все числа `font-variant-numeric: tabular-nums` через `.num` класс
- Десятичные через запятую: `12,5`, `74,8 кг`
- Дельты со знаком и пробелом: `+18 п.`, `−4`, `+0,3`, `−0,6 кг`
- Время сна в `H:MM` (`7:24`), дельта сна в `M:SS` со знаком (`+26:00`)
- Длительность: `1ч 20м`, `45 мин`, `60 минут`
- Температура: `+28°C`, `−3°C` (со знаком)
- Проценты: `78%` (без пробела перед `%`)
- AM/PM не используем. Только 24-часовой формат: `09:14`, `16:30`

---

## 14. Когда сомневаешься

1. Спроси **«что это значит в контексте Panditji?»** — это **личный** инструмент для **одного** человека, не SaaS-продукт
2. Cверь с существующими экранами в `design_handoff_*/` — есть ли там подобный паттерн?
3. Не добавляй UI-чанк без согласования. Лучше отметить место текстом «<сюда нужно X>» и спросить
